# Documentation

This directory contains project documentation generated from the AI assistant's memory system.

## Files

- `SETUP.md` - Quick start guide and development setup instructions
- `PROJECT_OVERVIEW.md` - Technical overview of the AI Journal application
- `TABLE_RESIZING_FIX.md` - Details of the recent table column resizing bug fix

## Memory System

These files are synchronized with the AI assistant's memory system:
- User memory: General knowledge that persists across all projects
- Session memory: Current conversation context (temporary)
- Repository memory: Project-specific facts stored locally

The files in this directory serve as both documentation and backup of the assistant's knowledge about this project.
